# How To Hosting

## Demo Lokal

1. Buka folder proyek `TOKO_SNACK`.
2. Buka `index.html` langsung di browser, atau jalankan server statis apa pun.
3. Tidak ada dependency, database, environment variable, atau port khusus.

## Deploy Static Hosting

Upload `index.html`, `styles.css`, dan `app.js` ke document root hosting. Pastikan ketiga file berada di folder yang sama.

## Data Demo

Data disimpan di `localStorage` browser dengan key `kriukpos-data`. Ini hanya prototype presentasi, bukan penyimpanan produksi.
