# ÉLORA Cosmetic Brand Demo

## Overview

Premium static multi-page beauty brand demo built for an upcoming presentation. The visual direction is quiet luxury with editorial typography, warm neutrals, moss green, and one saffron accent.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- GSAP 3 + ScrollTrigger via CDN
- Google Fonts and fixed Unsplash demo imagery

## Features

- Cinematic hero entrance: clip-path wipe, masked char-by-char typography, scramble eyebrow
- ScrollSmoother momentum scrolling with data-speed/data-lag parallax
- Scroll-pinned Renewal Serum story with Three.js WebGL fluid shader driven by scroll progress
- Horizontal product showcase with wheel hijack via ScrollToPlugin + Observer
- Eight-product catalog with Flip-animated category filter and price sort
- Flip add-to-bag flight animation into a draggable, inertial bag sheet
- Product detail page with accordions and add-to-bag quantity
- About and Journal editorial pages with ghost word and split-text reveals
- Editorial marquee with scroll-velocity skew, cursor follower, magnetic buttons
- LocalStorage cart drawer and cart page
- Responsive desktop, tablet, and mobile layouts
- Reduced-motion handling
- Typography reveal tuned to preserve Newsreader glyphs and trigger only inside the reading zone
- Non-blocking horizontal showcase observer so wheel scrolling never locks
- Horizontal showcase pin starts at the reading zone instead of while the rail is still low in the viewport
