# DEPPA

## Overview

DEPPA adalah API game Si Doel Smart Finance berbasis Laravel. Peserta mendaftarkan data diri, login memakai nama unik, menyelesaikan game, lalu mengunduh report dan certificate.

## Current Update

Google OAuth dihapus. Identitas peserta sekarang menggunakan `players.nama`; registrasi mengembalikan token Sanctum dan ID player sebagai metadata.
