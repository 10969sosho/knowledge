# Sebu Clinic Demo

## Overview
Premium static multi-page beauty website demo built from the brief for Sebu Clinic.

## Stack
- HTML
- CSS
- Vanilla JavaScript
- Google Fonts and fixed Unsplash demo imagery

## Features
- Editorial luxury beauty visual system
- Responsive pages for home, about, treatments, products, gallery, journal, reservation and contact
- WhatsApp reservation and product ordering flows
- Loading screen, page transition, scroll reveals, mobile menu, filters and gallery lightbox
- Lenis smooth scrolling, AOS reveal animation, branded overlay transitions, parallax and desktop cursor interaction
- Explicit `index.html` route links for compatibility when opening the demo with `file://`
