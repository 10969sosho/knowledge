# DEPPA Features

- Registrasi data diri peserta dengan nama unik.
- Login API menggunakan nama saja.
- Resume player dari main menu menggunakan nama.
- API dapat dipanggil dari Construct preview melalui CORS terkontrol.
- Penyelesaian game berdasarkan nama peserta.
- Download report dan certificate berdasarkan nama peserta setelah game selesai.
- Link report dan certificate dapat dibuka langsung di browser tanpa token.
- Dashboard admin untuk monitoring dan export data player.
